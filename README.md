# Daily Agent

A personal agent that reads my calendars, Obsidian tasks, and college email digest, then tells me what to do first today.

Start here: `START_HERE.md` is the easiest handoff to Claude Code (no installs needed).

More detail:
1. `docs/SETUP_CHECKLIST.md` for one time setup.
2. `docs/KICKOFF_PROMPTS.md` for the exact prompts to give Claude Code, in order.
3. `specs/` for the specs. `specs/00_principles.md` and `specs/01_overview.md` come first.
4. `docs/CHECKIN_LOG.md` to record progress every few days.
